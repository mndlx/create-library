# __REPLACE__

A React component library built with Vite and TypeScript.

## Scripts

- `npm run build` — build the library (ESM + CJS + types) to `dist/`
- `npm run typecheck` — type-check the sources

Additional scripts (`storybook`, `test`) are present when those features are enabled.

## Usage

```tsx
import { Card } from '__REPLACE__';
```
